# Requirements Archive: dragaocareca-admin-api v1.1

**Archived:** 2026-07-23
**Milestone:** v1.1 Public frontend API responses
**Closeout Type:** Override closeout
**Core Value:** Serve the public frontend with stable backend-owned data contracts so page rendering no longer depends on legacy PHP responses or client-side reconstruction rules.

## Completed Requirements

### Episodes Catalog

- [x] **CATALOG-01**: A public endpoint returns only published episodes.
- [x] **CATALOG-02**: Published episodes are returned in reverse chronological order for the home page.
- [x] **CATALOG-03**: Each catalog item includes the fields the home page needs for cards, search, and navigation.
- [x] **CATALOG-04**: Catalog responses include backend-owned media and page URLs so the frontend does not reconstruct legacy paths.

### Episode Detail

- [x] **DETAIL-01**: A public endpoint returns a single published episode by ID.
- [x] **DETAIL-02**: Episode detail responses include summary, playback/embed fields, download/media URLs, and credit/citation data required by the episode page.
- [x] **DETAIL-03**: Missing or unpublished episodes return a clear not-found response instead of leaking unpublished data.

### People and Site Metadata

- [x] **PEOPLE-01**: A dedicated public endpoint returns people/contact metadata used to render authors and credits.
- [x] **PEOPLE-02**: People data supports frontend credit resolution by member/name without the old `contacts.php` structure.
- [x] **SITE-01**: A dedicated public endpoint returns shared public-site metadata such as email, social links, support links, and character-sheet links.
- [x] **SITE-02**: Site metadata uses `supporters` terminology instead of `patreon`.

### Supporters

- [x] **SUPPORT-01**: A dedicated public endpoint returns the supporters data needed by the guilda/supporters page.
- [x] **SUPPORT-02**: Supporters responses can represent the current page content without requiring the legacy `patreon.php` endpoint.

### Verification and Documentation

- [x] **PUBLIC-01**: The backend documents the new public endpoints and their response shapes.
- [x] **PUBLIC-02**: Public endpoint work is verified against current frontend data needs with backend build and type checks.

## Requirement Outcomes

- All v1.1 scoped requirements are treated as complete at closeout.
- Phase 5 has executable verification evidence through `npm run verify:public-episodes`.
- Phases 6-8 were validated by reconciled code, OpenAPI surface, and shipped feature documentation during closeout on 2026-07-23.
