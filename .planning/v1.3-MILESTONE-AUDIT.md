**Status: gaps_found.** The checked-out source implements a different artifact-job API than the Phase 12 and 13 plans, summaries, and verification reports describe. The build and verifier pass, but the verifier covers that divergent API and cannot establish the v1.3 definition of done.

## Integration Findings

1. The Phase 12 parser supports an omitted `artifacts` query as default-all and a single CSV value. The current lifecycle requires a nonempty JSON array at `POST /v1/episodes/:episodeId/artifacts/jobs`, so that contract is not preserved.
2. Current lifecycle routes are `/artifacts/jobs`, `/artifacts/jobs/:jobId`, and `/artifacts/jobs/:jobId/download`. The recorded `/artifacts/prepare`, `/artifacts/preparations/:jobId`, and authenticated legacy `410` migration contract are absent.
3. The current preparation cache only checks archive existence, retains archives for 45 minutes, and reports fixed stage percentages. It lacks the documented SHA-256-or-missing evidence and source-byte Archiver progress.
4. Current OpenAPI and the compiled verifier accurately cover the artifact-job API, but that API differs materially from the committed Phase 13 documentation and its claimed verification evidence.

## Checks Run

`npm run typecheck`, `npm run build`, and `npm run verify:episode-artifact-downloads` passed. Those results do not clear the gaps because the compiled verifier targets the current divergent `/artifacts/jobs` contract.

## Nyquist Discovery

Both `12-VALIDATION.md` and `13-VALIDATION.md` exist but have `status: draft`. They are **not validated**, not compliance failures; run `$gsd-validate-phase 12` and `$gsd-validate-phase 13` after deciding the intended contract.

## Required Decision

Decide which contract is authoritative:

- Preserve the current `/artifacts/jobs` API, then rewrite v1.3 requirements, plans, summaries, verification, OpenAPI expectations, and tests to match it; or
- Restore the documented Phase 13 preparation API and implement its missing selector, cache, migration, progress, and public-safe error behaviors.

Do not complete or archive v1.3 until one contract is selected and its requirements are verified against the checked-out source.
