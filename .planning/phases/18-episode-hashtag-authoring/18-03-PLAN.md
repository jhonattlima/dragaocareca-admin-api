<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| summary completion → asynchronous authoring | A later summary generation can race external authoring work. |
| client → protected lookup route | A user-controlled tag reaches quota-sensitive provider lookup. |
| service DTO → OpenAPI/client | Only advisory/safe fields may cross the API boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18-08 | Tampering | `episode-summary.service.ts` | high | mitigate | Gate authoring after durable summary write and compare root state version plus summary digest before tag persistence. |
| T-18-09 | Denial of Service | manual lookup route | high | mitigate | Apply auth and no-store first, then use the shared normalizer, durable cache, one lane, and manual admission reserve. |
| T-18-10 | Information Disclosure | route/OpenAPI DTO | high | mitigate | Use explicit allowlists for retrieval/error fields; exclude transcripts, prompts, tokens, provider payloads, URLs, and ledger internals. |
| T-18-11 | Repudiation | persisted suggestions | medium | mitigate | Persist state timestamps, prompt version, summary digest, cache status, and safe retrieval metadata. |
| T-18-SC | Tampering | npm installs | low | accept | No package installation is planned. |
</threat_model>
