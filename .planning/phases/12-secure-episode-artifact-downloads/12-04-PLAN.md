<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → protected route | Untrusted path/query/header input crosses into an administrative export flow. |
| route → final artifact storage | Preflighted server paths are passed into the archive stream. |
| archive stream → HTTP response | A response becomes partially committed before late I/O errors can occur. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-01 | Information Disclosure / Tampering | route selector and archive entry handling | high | mitigate | Route consumes Plan 12-03 fixed catalog and preflight results only, sets explicit entry names, and never accepts a client path. |
| T-12-02 | Spoofing / Information Disclosure | download endpoint | high | mitigate | Apply existing `requireAuth`, preserve development-only bypass, and verify bearer rejection and bypass behavior directly. |
| T-12-04 | Information Disclosure | errors and operational logs | medium | mitigate | Return defined JSON/header selector messages and log only ID plus selector names, never absolute filesystem paths. |
| T-12-05 | Denial of Service / Integrity | Archiver response lifecycle | medium | mitigate | Attach listeners before finalization and destroy an already-streaming response on late archive failure rather than invoking normal Express error handling. |
| T-12-SC | Tampering | installed archive package | high | mitigate | Package was gated by the completed Plan 12-01 human review before route code imports it. |
</threat_model>
