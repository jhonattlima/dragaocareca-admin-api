<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authenticated command -> publication service | Untrusted metadata and route identity enter the guarded workflow. |
| Publication service -> filesystem | Cleanup can cause local data loss if keep-set and success gate are wrong. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-04 | Tampering | metadata validation/publication service | high | mitigate | Validate assembled Unicode title and forbidden characters before provider calls; derive summary, job, source, channel, and playlist from server state. |
| T-17-05 | Denial of Service | public privacy transition | high | mitigate | Playlist insertion precedes public update; failed/ambiguous pre-publication operations remain private and retryable. |
| T-17-06 | Denial of Service | retention cleanup | high | mitigate | Calculate keep-set before deletion, use regular-file checks, gate on confirmed publication, and record deletion failures without public rollback. |
| T-17-07 | Tampering | stale source replacement | high | mitigate | Recheck canonical source fingerprint and guarded revision before every external side effect and URL/state write. |
| T-17-SC | Tampering | npm/pip/cargo installs | low | accept | No package-manager install is introduced; the implementation uses existing dependencies. |
</threat_model>
