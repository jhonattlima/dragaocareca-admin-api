## YouTube Data API Coverage Matrix

| API operation | Decision | Reason |
|---|---|---|
| videos.list for the recorded provider video | INTEGRATE | Confirm the same private-ready video before playlist insertion, reconcile ambiguous outcomes, and confirm public state before persistence. |
| videos.update with complete snippet metadata | INTEGRATE | Apply operator title/selected hashtags and the exact final saved summary without relying on omitted mutable fields. |
| videos.update with narrow status.privacyStatus | INTEGRATE | Perform the only public transition after playlist confirmation. |
| playlistItems.list | INTEGRATE | Detect existing membership before retrying an uncertain insert and make repeated publication idempotent. |
| playlistItems.insert | INTEGRATE | Add the configured target playlist item while the provider video remains private. |
| OAuth token-info/readiness check | INTEGRATE | Verify server-side edit-capable authorization and configured channel before live publication. |
| channels.list | OPT-OUT | The authenticated channel ID is deployment configuration and the publication contract does not need a discovery lookup; avoid adding a second authority or network dependency. |
| playlistItems.delete | OPT-OUT | Failed pre-publication operations must remain private; compensating playlist deletion could remove an operator-owned existing membership and is not required by the locked invariant. |
| videos.delete | OPT-OUT | Provider videos are retained for recovery and local retention is the only cleanup scope; deletion would violate the preservation boundary. |
| search.list | OPT-OUT | Hashtag authoring/count lookup belongs to Phase 18; publication consumes selected operator input only. |
| YouTube Analytics endpoints | OPT-OUT | Analytics are outside TRAILER-04/07/08 and already have a separate existing connector. |
