<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| transcript artifact -> summary runtime | Untrusted transcript content is converted into prompt input for a local CLI |
| summary runtime -> local CLI process | Runtime arguments and transcript-derived content must not cross a shell boundary |
| shared episode state -> concurrent summary jobs | Multiple queued or interrupted jobs must not overwrite the newest state or artifact |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-04 | Elevation of Privilege | `src/services/episode-summary.service.ts` CLI invocation | high | mitigate | Invoke the configured summary binary only through `execFile` with argument arrays; never use `exec`, `shell: true`, or transcript text interpolation in the command line. |
| T-09-05 | Tampering | `src/services/episode-summary.service.ts` shared-state writes | high | mitigate | Version all draft-summary writes, re-check current state before terminal artifact updates, and let later queue requests supersede stale work per D-03 and FLOW-02. |
| T-09-06 | Information Disclosure | `src/scripts/verify-summary-runtime-contract.ts` and service logs | medium | mitigate | Keep verification fixtures local, avoid logging full transcript bodies, and validate summary ownership without copying transcript content into unrelated artifacts. |
| T-09-SC | Tampering | npm installs | low | accept | No package installation is planned for Phase 09; reuse the existing dependency set only. |
</threat_model>
