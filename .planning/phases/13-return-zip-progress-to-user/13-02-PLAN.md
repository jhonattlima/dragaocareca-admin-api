<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client to lifecycle routes | Request IDs, selectors, and job IDs are untrusted even when authenticated. |
| server bootstrap to worker | Restart recovery must not launch overlapping archive execution. |
| ready archive to HTTP response | A file may change or expire between reported status and stream open. |

## STRIDE Threat Register — ASVS L1

High-severity threats block plan completion.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-04 | Elevation of privilege | prepare/status/download routes | high | mitigate | Apply `requireAuth` to every lifecycle and migration route; preserve only development AUTH_BYPASS behavior. |
| T-13-05 | Information disclosure | status and ZIP responses | high | mitigate | Serialize allowlisted status fields only, add no-store headers, and stream only service-validated archive handles. |
| T-13-06 | Denial of service | worker and direct route | high | mitigate | Start one guarded FIFO worker and retire direct live-stream behavior to an authenticated migration response. |
| T-13-07 | Tampering | job/episode association | high | mitigate | Validate positive IDs and enforce service lookup scoped to both opaque job ID and episode ID before status/download. |
| T-13-08 | Repudiation | lifecycle operations | low | accept | Selector-only event logs retain operational events without adding deferred download audit records. |
</threat_model>
