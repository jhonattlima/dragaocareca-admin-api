## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| selector input to preparation service | Untrusted query input must select only the closed Phase 12 catalog. |
| canonical final files to snapshots/cache | Filesystem contents can change between preflight, copy, cache reuse, and download. |
| persisted manifest to restart processor | On-disk lifecycle state survives process loss and must not authorize stale or partial output. |

## STRIDE Threat Register — ASVS L1

High-severity threats block plan completion.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-01 | Tampering | ready cache and source fingerprints | high | mitigate | Persist a streaming SHA-256 digest for every requested regular source and a missing marker for every unavailable selection; revalidate the complete map before ready status/download, then expire and remove changed output. |
| T-13-02 | Information disclosure | snapshots, manifests, and logs | high | mitigate | Persist generated basenames/selectors/fingerprints only; archive fixed snapshots; omit paths from logs, status, and errors. |
| T-13-03 | Denial of service | ZIP construction | high | mitigate | Durable FIFO plus module-local active promise limits the VPS to one archive and cleans expired/interrupted work. |
| T-13-04 | Tampering | incomplete ZIP publication | high | mitigate | Use job-local snapshots, temporary output, stream completion, then same-directory rename before `ready`. |
| T-13-05 | Repudiation | preparation operations | low | accept | Selector-only lifecycle event logs provide operational traceability without adding out-of-scope audit records. |
| T-13-06 | Elevation of privilege | generated job identifiers | medium | mitigate | Use cryptographically generated opaque IDs; later routes also require existing authentication. |
</threat_model>
