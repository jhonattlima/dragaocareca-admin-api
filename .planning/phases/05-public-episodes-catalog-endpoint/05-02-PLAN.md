| T-05-07 | Spoofing | public URL fields | medium | mitigate | Keep URL generation centralized and documented so clients consume backend-declared absolute URLs rather than constructing host-specific paths. |
| T-05-SC | Tampering | npm installs | low | accept | No package installation is planned for this phase. |
